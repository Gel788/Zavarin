## 1. Аудит текущей версии (v5)
**Стек:** статический HTML + один общий pages.css (8 КБ) + инлайн-`<style>` на страницах; vanilla JS (common/home/catalog/product.js, 3–12 КБ); GSAP 3.12.5 + ScrollTrigger + Flip + Lenis с jsDelivr; данные — products.json (44 товара, 8 категорий, цены/спеки с zavarin.art). Фреймворка и сборки нет.

**Шрифты:** Cormorant Garamond (300–500, ital), Cormorant SC, Manrope 300–500 (Google Fonts, 3 семейства, ~10 начертаний).

Для полноэкранного hero качество фона (баннер 1800 px) на грани; вырезки — только до ~520 px высоты на 1x.
**Анимации:** авто-слайдер hero (7 с, Ken Burns scale 1.12→1.02), reveal-on-scroll, параллакс, Lenis smooth-scroll, FLIP в каталоге, скелетоны. reduced-motion обрабатывается частично (только hero).
**Интеракции:** избранное/корзина (localStorage), quick-add, фильтры, drawer/bottom-sheet, плотность сетки.
**Адаптив:** скриншоты audit/*-{1440,1024,768,390,320}.png (+ hero-1440/390 с реальной высотой). Брейкпоинты работают, переполнения нет.
**Производительность:** страница тянет 3–4 CDN-скрипта (~110 КБ gzip GSAP+плагины+Lenis), PNG-вырезки 450–820 КБ каждая в hero (5–6 шт.), нет preload LCP, нет width/height у img → CLS.
**Доступность:** семантика header/section/footer есть, main нет; 4 `alt=""` у содержательных фото; карусель hero автоплей без паузы по фокусу; мелкий текст 11–12 px Cormorant SC #a99a80 на #0e0b09 (контраст ≈6:1 — ок, но кегль мал); стиль :focus-visible не задан; в футере `<a>` без href.

## 2. Концепция «Тихая литургия»
### 2.1 Принципы
Сдержанная роскошь: мало золота, много воздуха, предмет — единственный герой. Чёрный «студийный» верх → тёплые слоновокостные редакционные развороты → чёрный финал. Никаких частиц, свечения, дыма, курсора, автослайдеров, smooth-scroll.

### 2.2 Палитра
| токен | hex | роль |
|---|---|---|
| --black | #0b0b0c | hero, финал, футер |
| --graphite | #17181a | шапка при скролле, тёмные секции |
| --graphite-2 | #232427 | плашки, линии на тёмном #2e2f33 |
| --ivory | #f3eee4 | редакционные секции |
| --ivory-2 | #e9e2d4 | подложки фото на светлом |
| --ink | #1b1a18 | текст на ivory (контраст 15:1) |
| --stone | #6d675d | вторичный текст на ivory (5.3:1) |
| --gold | #b39a68 | приглушённое золото, только линии/акценты/ссылки; на тёмном текст #c9b48a |
Золото без градиентов. Доля золота на экране ≤3%.

### 2.3 Типографика
- Display: **Cormorant Garamond** 300/400 + italic (кириллица, выразительные засечки на крупном кегле). Cormorant SC убрать.
- Текст/UI: **Onest** 400/500 (современный гротеск с хорошей кириллицей) вместо Manrope 300 (слишком тонкий для текста).
- Шкала (desktop/mobile): Display 120/56 lh .95 ls -0.02em; H1 88/44; H2 64/36 lh 1.02; H3 32/24; Lead 22/18 lh 1.5 (Cormorant 400); Body 16/15 lh 1.65 (Onest); Small 13/13; Label 11/11 Onest 500 uppercase ls .16em. Clamp-интерполяция между 390 и 1440.

### 2.4 Сетка
12 колонок, max 1440, поля 64/40/20 px (≥1200/≥768/<768), гаттер 24/16. Асимметрия: текст 4–5 колонок со смещением на 1, изображения 6–7 колонок с выходом за поле. Вертикальный ритм секций 160/120/88 px.

5. **Избранные изделия** — graphite; 4 карточки (2 креста, кольцо, икона) из products.json, фото на тёплом сером #e9e6df вместо чистого белого, название Cormorant 22, цена Onest 15, без бейджей.

### 2.6 Каталог/карточки
Фон ivory вместо чёрного; карточка: фото 4:5 на #ebe7df, padding 10%, при hover — второе фото crossfade 400 мс; под фото название 2 строки Cormorant 20, цена/старая цена Onest. Сетка 4/3/2/2 колонки, гаттер 24/16. Фильтры — горизонтальные текстовые чипы с подчёркиванием, не пилюли. Баннеры внутри сетки убрать, кроме одного (Индивидуальные работы).
### 2.7 Микро-интеракции
Hover ссылок — подчёркивание растёт слева 300 мс; кнопки — смена фона 200 мс; фото — scale 1.03 за 900 мс; появление секций — opacity+translateY 16px, 700 мс, один раз. `prefers-reduced-motion`: всё мгновенно, без трансформаций. :focus-visible — 2 px outline gold с offset 3 px.
### 2.8 Мобильная версия
Отдельная композиция: hero — крест сверху (высота 52svh), текст под ним, кнопка на всю ширину; коллекции — вертикальный список 1 колонка с фото 4:3; избранное — горизонтальный scroll-snap 78vw; мастерская — фото, затем этапы; кегли по шкале mobile; hit-area ≥44 px.
### 2.9 Hero: фото vs 3D
Фото креста с zavarin.art — 1000×1000 на белом, вырезка 509×824: резкое, детализированное, корректный металл и камни — достаточно для hero до ~620 px высоты (на retina слегка мягче). 3D-модели у бренда в открытом доступе нет; генеративный «фотореал» нарушил бы требование «только реальное». Решение: использовать реальный кадр сейчас, рекомендовать бренду предметную съёмку 4000+ px на чёрном (или их собственную 3D-модель, которую они делают на этапе моделирования) для финальной версии.
### 2.10 Удалить
GSAP, Lenis, авто-слайдер, Ken Burns, прогресс-бары, круглые стрелки, Cormorant SC, градиентное золото, index_v1/v4 и app*.js (не используются), непроверяемые цифры.
